# ULINZI-PI
This study therefore seeks to design, develop, and evaluate ULINZI-PI, a portable Raspberry Pi-based penetration testing platform tailored to the operational needs of SMEs. Through integrating selected open-source security tools into a single embedded platform and evaluating its technical performance under deployment conditions, the study aims to provide evidence on the feasibility of affordable cybersecurity solutions for improving vulnerability assessment among Kenyan SMEs.
